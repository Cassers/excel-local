Archivos grandes

Para Excel o CSV de 100–500 MB, inicia el servicio local. Los datos se guardan temporalmente en tu disco y el navegador muestra solo una página.

En la carpeta del proyecto, ejecuta:

./abrir.sh

Después abre http://127.0.0.1:8768/ y pulsa «Archivos grandes».

El tamaño posible depende del espacio en disco, la memoria y el contenido. Los XLS antiguos deben convertirse a XLSX. Este modo permite editar, pegar, buscar y exportar; mantiene la estructura de las hojas.

Renombrar una hoja

Usa punto decimal para introducir números (1234.56). Para mantener ceros iniciales o forzar texto, empieza con un apóstrofo: '00123. Se conservan los tipos del archivo importado.

Este editor trabaja con datos. Gráficos, macros, estilos avanzados y combinaciones de celdas no se conservan. Las fórmulas se muestran como texto editable y se guardan para calcularse en Excel. No hay guardado automático: descarga antes de cerrar.
